# Liminal Anatomy｜阈限解剖

**副标题：Decoding the Shared Perception of Indeterminacy**

**关盛豪（Shenghao Guan）** · 多伦多大学建筑学硕士（Post-Professional MArch）· 2026

本项目研究“阈限空间”（Liminal Space）的概念演变、建筑空间特征与心理感知，并探讨如何从对空间氛围的观察与分析转向主动设计。

## 三个研究问题

1. **什么是阈限空间？** 从人类学的阈限概念，到建筑空间，再到网络时代的数字审美。
2. **阈限空间告诉我们什么？** 研究陌生感、怀旧、疏离等心理体验与空间条件之间的关系，并进行探索性感知调查。
3. **如何应用阈限空间研究？** 提出 TSEP 分析模型与 Kit of Parts，最终通过 **The Liminal Box** 互动展览开展设计实验。

## 主要研究成果

- **TSEP（Time / Space / Event / Perception）模型**：从时间、空间、事件和感知四个维度组织阈限空间分析。
- **Kit of Parts**：用于构建与调整阈限氛围的设计元素与方法。
- **The Liminal Box**：通过互动装置探索参与者对空间变化的感知，包含 Office 和 Playroom 两个场景。
